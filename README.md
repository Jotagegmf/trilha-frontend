# 💻 Trilha Front-end

Bem-vindo ao meu repositório de estudos e práticas de Front-end! 

Este espaço concentra meus códigos e pequenos projetos focados na construção de interfaces web. O objetivo deste repositório é documentar a evolução da minha base técnica e centralizar meus aprendizados práticos.

## 🛠️ Tecnologias Abordadas
Aqui você encontrará aplicações e exercícios utilizando:
- **HTML5 & CSS3:** Semântica, responsividade (Flexbox/Grid) e estilização.
- **JavaScript:** Lógica de programação, manipulação de DOM e ES6+.
- **React & TypeScript:** Componentização, props, hooks e tipagem estática.

## 📂 Estrutura de Pastas
Para facilitar a navegação, os estudos estão organizados por temas:

- `/01-fundamentos-html-css`: Desafios de layout e estruturação de páginas estáticas.
- `/02-javascript-pratica`: Exercícios de lógica, algoritmos e pequenos scripts no navegador.
- `/03-projetos-react`: Primeiras aplicações componentizadas e consumo de APIs.
