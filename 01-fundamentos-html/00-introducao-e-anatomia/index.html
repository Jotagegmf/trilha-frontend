HTML - HyperText Markup Language

O que são linguagens de marcação? (Markup Languages)

Linguagens de marcação não é uma linguagem de programação, visto que não possuem lógica matemática, variáveis, loops ou condicionais...

O objetivo é anotar e estruturar textos para que algum software - Navegadores, consigam interpretar e processar

Como funciona:

  • Semântica: As tags dizem ao navegador se aquele trecho é um título, um parágrafo, uma imagem, uma lista...
  • Por que isso importa? Isso traz organização, facilidade de manutenção, aumento de acessibilidade (pessoas com deficiência visual necessitam), e SEO (ferramentas de busca).
  • Existem outras lingaugens de marcação como XML (voltada para transportar dados) e Markdown (usado principalmente em documentos).

Comentários são feitos assim: <!--> comentário --> . Esses comentários não ficam visíveis diretamente para o usuário. Podem ser importantes para deixar algo específico para quem for dar manutenção, esconder algum bug momentâneo, etc...

Algumas pequenas observações:

  • O HTML não é Case Sensitive, ou seja, <BODY>, <body> ou <BoDy>, vão ser interpretados da mesma forma.
  • Mas por convensão, escrevemos todas as tags em minúsculas
  • O HTML ignora espaços brancos extras (White Space Collapse)
  • Para quebra de linhas, usa-se a tag especial < br > .
  • Espaços em branco usa-se a entidade &nbsp;
  • Essas estilizações podem, e devem ser feitas, preferencialmente, utilizando CSS
